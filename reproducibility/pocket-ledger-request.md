Build a production-ready personal expense ledger web app called "Pocket Ledger". Stack: React + TypeScript (Vite), react-router-dom, React context + reducer for shared state, plain CSS with design tokens (no CSS framework), Vitest for unit tests, no external network requests, mock data only. Routes: "/" (this month: total spent, budget remaining, top 3 categories, last 5 expenses), "/expenses" (list with search, category and date-range filters, sort by date or amount; filter state in the URL), "/expenses/:id" (detail with edit and split editor), "/budgets" (per-category monthly budgets with progress bars), "/reports" (monthly totals per category for the last 6 months as inline SVG bars). Rules that must be pure functions with unit tests: 1. All money is integer cents; never float arithmetic on amounts. 2. An expense can be split among 1-5 people in whole percentages that must sum to 100; each share is rounded to the nearest cent and the LAST share absorbs the rounding difference so the shares sum exactly to the amount. 3. A category budget is EXCEEDED when the month total is strictly greater than the budget; at exactly the budget it is NOT exceeded. 4. Monthly totals use the expense date in the local timezone; an expense at 23:59 on the last day of a month belongs to that month. 5. A 2.5% foreign-transaction fee applies to expenses in a currency other than USD, computed on the cents amount and rounded half up to the nearest cent. Persist all changes to localStorage. Light-first theme with a dark toggle, keyboard-reachable controls, a seeded data set of 40 expenses across 6 categories and 3 months with at least 4 split expenses and 3 foreign-currency ones.
