# The run the case study leads with — 2026-09-29 (TensorFold)

Run `k3-tensorfold-2026-09-29a`, 18:02Z to 19:48Z. Same prompt, same model checkpoint and
same laptop as the 2026-09-14 run; the model is served by TensorFold with speculative
decoding instead of LM Studio. Unattended after the prompt, by construction of the runner.

**Artifacts.** The run journal (`run-journal.json`), the run report, the console log, the
serving configuration and serve log, the session log (every model call), the closeout
scorecard and the oracle results are being prepared for publication and will be added to
this folder soon. Until then this file holds every figure with the artifact it was measured
from. Nothing here is estimated. The application built by this run has not been published
either; the receipts repository holds the 2026-09-14 application.
